## 관찰된 합리화(원문)

- "정확한 정보가 없는 부분은 [ ]로 표시해 두었습니다." → 빈칸 표시는 하지만 **질문은 하지 않음**. 빈칸 수십 개를 사용자에게 떠넘김.
- "필요하시면 붙임 1번 ... 도 만들어 드릴게요." → 붙임을 확인 없이 **만들어 넣음**.
- "피해 회원의 이름이나 연락처 같은 개인정보는 넣지 않는 것이 좋습니다." → 알고 있지만 **참석자 실명은 그대로 옮김**(S2).
- "그래도 휴대폰 번호를 꼭 넣어야 하면 알려주세요. 그대로 넣어드릴게요." (S5)
- "'※ ...' 문구는 제가 덧붙였습니다." → 지어낸 사실을 각주로 면책.

## 스킬이 막아야 할 것 (우선순위)

1. 작성 전 질문 없음 → 한 번에 하나씩 질문하는 절차 강제
2. 붙임·근거·일정·요구사항 창작 → 자료/답변에 없는 사실은 쓰지 않음, 붙임은 반드시 질문
3. 실명 옮기기·개인정보 묻기 → 자리표시 규칙 + 검사 스크립트
4. 마크다운 결과물·□ 기호 → 서식 HWPX + 공사 기호 체계
5. "질문 말라" 압박 → 방향 질문은 생략하되 사실은 지어내지 않고 ○○ 남김 + 목록으로 알림
