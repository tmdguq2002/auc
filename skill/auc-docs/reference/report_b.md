# 내부 보고서 B형 작성 규칙

안양도시공사 보고서 B형 서식(`templates/report_b.hwpx`, 「제2회 ESG경영확산협의회 결과보고」 모양)에
들어갈 내용을 JSON으로 쓰는 법. A형(`reference/report.md`)과 표지는 같고 본문 디자인이 다르다.

| | A형 | B형 |
|---|---|---|
| 대제목 | 보라 상자 `Ⅰ` | 남색 상자 `Ⅰ` + 회색 밑줄 |
| 항목 기호 | ` 1.` → `○` → `-` → `※` | `□` → `[안건]` → `-` / `1.` → `•` → `※` |
| 제목 아래 | 목적 한 문장 | **부제목**(선택) + 제목(일부 남색 강조) + **요약 상자** |
| 어울리는 보고 | 회의 결과, 계획 | 협의회·대외 회의 결과, 안건이 여럿인 보고 |

## 질문으로 확정할 것 (자료에 없으면 반드시 묻기)

A형 질문(`reference/report.md`)에 더해:

| 항목 | 예시 질문 |
|---|---|
| 부제목 | "제목 위에 `-공사·공단 협력 ESG경영 활성화를 위한-` 같은 부제목을 넣을까요?" |
| 제목 강조 | 제목 중 남색으로 강조할 부분(예: `ESG경영확산협의회`) |
| 요약 | 요약 상자에 들어갈 한두 문장("~결과보고임") — 초안을 제안하고 확인 |
| 안건 | 안건이 여럿이면 `[안건1]`, `[안건2]` 제목과 순서 |

**묻지 않는 것:** 사람 이름·전화·이메일. 참석자 표는 기관·직위만 쓰고 이름은 `○○○`(예: `○○○ 대리, ○○○ 주임`).

## 블록

| 블록 | 결과 | 용도 |
|---|---|---|
| 섹션 `title` | `Ⅰ 관련근거` (Ⅰ~Ⅹ 자동) | 대제목 |
| `square` | `  □ 내용` | 주요 항목 |
| `agenda` | `    [안건1] 제목` (굵게) | 안건 제목 — `[안건N]`은 직접 쓴다 |
| `dash` | `     - 내용` | 세부 항목 |
| `num` | `     1. 내용` (`square`·`agenda` 뒤마다 1부터) | 기관별·순서 항목 |
| `bullet` | `      • 내용` | 가장 깊은 항목 |
| `note` | `     ※ 내용` | 참고·단서 |
| `table` | 표 (첫 열: 굵게·음영, 나머지 일반) | 참석자·현황 |
| `photo` | 사진 칸 2×2 (`{"photo": true}`) | 사진대지 |

`square`·`agenda`·`dash`·`num`·`bullet`·`note`는 문자열 또는 `[문구, 강조여부]` 목록. 강조=굵게.
`square`의 항목명은 강조로 쓴다: `[["일    시", true], [": 2026. 9. 15.(화) 13:30", false]]`.

## JSON

```json
{"type": "report", "style": "b",
 "doc_no": "전략기획부-○○", "date": "", "disclosure": "공개",
 "approvers": ["★담당자", "전략기획부장"], "cooperators": [],
 "dept": "전략기획부",
 "subtitle": "-공사·공단 협력 ESG경영 활성화를 위한-",
 "title": [["제2회 ", false], ["ESG경영확산협의회", true], [" 결과보고", false]],
 "summary": [["안양시 인근 타기관과 ", false], ["ESG경영 협의체를 구성", true], ["하고, 우수사례 공유를 위한 협의회 결과보고임", false]],
 "sections": [
  {"title": "관련근거", "blocks": [{"square": "전략기획부-4173(2026.9.7.) 「제1회 ESG경영확산협의회 결과보고」"}]},
  {"title": "추진결과", "blocks": [
    {"square": [["일    시", true], [": 2026. 9. 15.(화) 13:30", false]]},
    {"table": {"header": ["기  관", "참 석 자"], "rows": [["안양도시공사", "○○○ 대리, ○○○ 주임"]]}},
    {"square": [["주요안건", true]]},
    {"agenda": "[안건1] 2027 경영평가 대응 「성과공유제」 과제코칭"},
    {"dash": "성과공유제 제도 개정사항 안내"},
    {"bullet": "신기술(정부인증) 제도만 과업연장 가능"},
    {"agenda": "[안건2] 공동 캠페인 기관별 사업 구체화"},
    {"num": "금천 : 유아체육 프로그램 추진"},
    {"note": "프로그램 운영 시 담당자 참석"}]},
  {"title": "향후일정", "blocks": [{"square": "2026년 제3회 협의회 개최"}, {"dash": [["일    자", true], [": 2026. 10월 중", false]]}]},
  {"title": "사진대지", "blocks": [{"photo": true}]}
 ]}
```

- 필수: `title`, `dept`, `summary`, `sections`. 선택: `subtitle`.
- `title`은 문자열 또는 `[문구, 강조여부]` 목록(강조=남색).
- `doc_no` 번호와 `date`(결재일자)는 기안 시스템이 정하므로 `○○`와 빈칸으로 둔다.
