# 요지 작성 규칙

안양도시공사 요지 서식(`templates/yoji.hwpx`)에 들어갈 내용을 JSON으로 쓰는 법.
요지는 **항상 한 장**이다. 행사·계획·현황·법령 등 한 주제를 윗선에 빠르게 보고할 때 쓴다.
서식에는 참고용 요지 두 장이 들어 있고, 내용에 따라 둘 중 하나의 모양을 따른다.

| 참고 요지 | 모양 | 언제 |
|---|---|---|
| 「춘(春)나게 소통」계획 | 글 위주, 줄간격 넓게(200%), 사진 칸 | 행사·계획 |
| 중대재해처벌법 개요 및 사례 | 표 위주, 줄간격 좁게(160%) | 법령·사례·현황 |

본문에 `table`이 있으면 자동으로 둘째 모양(160%)을, 없으면 첫째 모양(200%)을 쓴다.

## 쪽 구성 (스크립트가 그림)

머리(로고 · "존중과 성장의 안양도시공사" · 날짜 · 부서) → 색 띠 → **제목** → 라벨(`개  요`) → 본문

## 질문으로 확정할 것 (자료에 없으면 반드시 묻기)

| 항목 | 예시 질문 |
|---|---|
| 날짜 | 머리 오른쪽 위 날짜. "보고일(또는 행사일)을 언제로 할까요?" |
| 부서 | 머리 오른쪽 위 부서명 |
| 제목 | 초안을 제안하고 확인 |
| 라벨 | 기본 `개  요`. 다른 말(`현  황`, `추진계획`)이 좋을지 |
| 사실관계 | 일시·장소·인원·금액·법령 조항·사례. 자료에 없으면 지어내지 않고 질문 |
| 표·사진 | 표로 정리할 내용, 사진 칸(2개)과 설명 문구 |
| 강조 | 굵게 할 핵심 문구 |

**묻지 않는 것:** 사람 이름·전화·이메일. 직위(사장, 안전감사팀장)는 써도 된다.

## 문체

- 개조식, 명사형 종결: "~이동", "~점검", "~수사 진행 중".
- `❍ 항목명 : 내용` 형식으로 쌍점 앞뒤 한 칸. 항목명 글자 수가 다르면 공백으로 맞춘다(`시    간`, `참석인원`).
- **한 장에 들어가도록 짧게.** 자료가 많으면 핵심만 고르고, 무엇을 뺄지 질문한다.
  주제가 둘 이상이면 요지를 따로 만들자고 제안한다(한 파일에 여러 장 넣지 않는다).

## 블록

| 블록 | 결과 | 용도 |
|---|---|---|
| `circle` | ` ❍ 내용` | 주요 항목 |
| `dash` | `  - 내용` | 세부 항목 |
| `note` | ` ※ 내용` | 참고·단서 |
| `table` | 표 (머리행 + 행, 열 너비 자동) | 법령·사례·현황 |
| `photo` | 사진 칸 2개 + 설명 2개 (`["설명1", "설명2"]`) | 지도·현장 사진 자리 |

`circle`·`dash`·`note`는 문자열 또는 `[문구, 강조여부]` 목록. 강조=굵게.
표가 있는 쪽은 줄간격이 자동으로 좁아진다(원본과 같음). 사진은 한글에서 빈 칸에 넣는다.

## JSON

글 위주(첫째 모양):

```json
{"type": "yoji",
 "date": "2026. 3. 27.(금)", "dept": "안전감사팀",
 "title": "안전감사팀「춘(春)나게 소통」계획",
 "blocks": [
  {"circle": "시    간 : 11:00 ~ 13:00"},
  {"circle": "참석인원 : 7명(사장, 안전감사팀장 등 6명)"},
  {"circle": "활동내용"},
  {"dash": [["춘(春)나게 걷기", true], [" : 잣나무 숲까지 봄 향기를 맡으며 이동", false]]},
  {"photo": ["도보 이동거리(17분)", "관악산 산림욕장(잣나무숲)"]}]}
```

표 위주(둘째 모양):

```json
{"type": "yoji",
 "date": "2026. 3. 30.(월)", "dept": "안전감사팀",
 "title": "중대재해처벌법 개요 및 사례",
 "blocks": [
  {"circle": [["처벌대상 : 사업주 또는 ", false], ["경영책임자", true]]},
  {"circle": "주요 사례"},
  {"table": {"header": ["일  자", "개  요"], "rows": [["2022년 3월", "(코레일) 열차 하부 점검 중 사망"]]}}]}
```

- 필수: `title`, `blocks`. 선택: `date`, `dept`, `label`(기본 `개  요`).
- 날짜 형식 `2026. 3. 27.(금)`.
